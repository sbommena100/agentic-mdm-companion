# Agentic MDM Companion Pack

Companion resources for **Agentic MDM: Master Data Management for the Autonomous Enterprise — First Edition**.

This repository is the official distribution point for the book's practitioner companion resources, including exercises, worked solutions, schemas, static fixtures, architecture resources, evaluation material and governance artefacts.

## What's Included

The companion pack contains:

- **CP01–CP10** — reader exercises and practitioner resources
- **SP01–SP10** — worked solutions and answer packs
- Structured worksheets and templates
- JSON and JSONL fixtures
- JSON Schema resources
- Architecture and governance artefacts
- Evaluation and decision-support materials

Exercises are optional enrichment. The book can be read independently without completing the companion activities.

## How to Use the Pack

Download the ZIP from the latest GitHub Release and extract it locally.

Start with the guidance included inside the companion pack, then open the CP resource referenced by the relevant chapter. Worked solutions are provided separately so that exercises can be attempted before reviewing the suggested answers.

## About the Companion Resources

The materials are designed for practitioner learning and architectural exploration. Examples, organisations, identifiers and scenarios used in the exercises are synthetic or illustrative unless explicitly stated otherwise.

The companion resources should be used together with the explanations, architecture patterns and governance boundaries described in the book.
